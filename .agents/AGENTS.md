# Правила работы для ассистента в проекте OknaCompany 🚀

Для экономии токенов и ускорения работы придерживайся следующих правил:

## Чтение файлов и поиск
1. **Точечный просмотр:** Никогда не читай файлы целиком (более 50 строк за раз). Используй `view_file` с точным указанием `StartLine` и `EndLine` (не более 30-50 строк вокруг целевого блока).
2. **Точечный поиск:** Для поиска классов и стилей используй `grep_search` или точные команды PowerShell (`Select-String`), вместо построчного перебора или вывода больших секций CSS/JS.
3. **Использование карты проекта:** Пользуйся существующим руководством по структуре проекта `codebase_guide.md` в истории разговоров, чтобы сразу понимать, за что отвечает каждый файл.

## Общение с пользователем
1. **Лаконичность:** Пиши сообщения в чате максимально коротко. Все технические подробности, диффы и чек-листы выноси в артефакты (`walkthrough.md`, `task.md`, `implementation_plan.md`).
2. **Ссылки на файлы:** Всегда оформляй ссылки на файлы проекта в виде кликабельных ссылок стандарта GitHub (например, `[style.css](file:///c:/Users/vladi/OneDrive/Документы/CompanyWindow/style.css)`).

## Работа с окружением
1. Очищай временные файлы (изображения Figma, JSON-ответы API) сразу после завершения шага, чтобы они не засоряли рабочую директорию.
